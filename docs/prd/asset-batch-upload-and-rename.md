# 素材批量上传与展示名称编辑 PRD

## 1. 目标

为运营和设计师提供统一的素材管理体验：一次选择多张产品图或电商模板图，查看逐张上传状态并处理失败项；上传后可编辑资产展示名称，同时保留原始文件名和 TOS 存储路径用于追溯。

本期不改变图层模板编辑器，不把电商模板图转换为 `LayerTemplate`，不提供批量自动命名或图片去重。

## 2. 用户与权限

- `operator` 与 `designer`：素材管理能力一致，进入同一素材管理页面，复用同一组件和 API。
- `admin`：使用同一页面，并可管理全部资产。
- 查看：所有者可查看自己的全部资产；其他登录用户可查看公开资产；管理员可查看全部资产。
- 修改展示名称、可见性、标签和删除：仅所有者或管理员。
- 角色差异只保留在素材管理之外的业务模块。

## 3. 入口与信息架构

- 主导航提供统一“素材管理”入口，不分别实现运营图库和设计师图库。
- 现有运营图库迁移为共享素材管理模块；设计师页面通过导航进入同一模块，不复制图库逻辑。
- 页面保留列表、搜索、类型、范围、标签、批量管理和资产详情能力。
- 搜索框文案改为“搜索展示名称 / 原始文件名 / 标签”。

## 4. 批量上传主流程

1. 用户点击“上传图片”。
2. 在上传弹窗选择本批资产类型：产品图或电商模板图。
3. 用户一次选择 1 至 50 张图片，文件进入等待队列。
4. 客户端逐文件预校验；不合格文件显示具体原因，不进入上传并发槽。
5. 客户端最多并发上传 3 张，每张独立调用 `POST /api/assets/upload`。
6. 每张图片独立成功或失败；成功项立即形成资产，不因其他文件失败而回滚。
7. 失败项可单独重试；等待项可移除；上传中项目可取消客户端请求。
8. 全部项目进入终态后，用户点击“完成”回到素材列表。
9. 列表刷新并自动进入批量选择状态，选中本批成功创建的资产。
10. 用户在列表中统一设置公开/私有和标签；上传弹窗不承载这些操作。

## 5. 上传规则

| 规则 | 要求 |
|---|---|
| 批次数量 | 最多 50 张 |
| 批次类型 | 同批仅一种：`product_image` 或 `template_material` |
| MIME | `image/jpeg`、`image/png`、`image/webp` |
| 单文件大小 | 不超过 20MB |
| 最小尺寸 | 200 x 200 |
| 并发数 | 3 |
| 默认可见性 | `private` |
| 所有者 | 当前登录用户 |
| 默认展示名称 | 原始文件名去掉最后一个扩展名后缀 |
| 重复处理 | 不按文件名、展示名称、checksum 或内容自动去重 |

同批存在相同默认展示名称时只提示“名称重复”，不阻止上传。重复图片分别创建独立资产 ID。

## 6. 队列状态与操作

| 状态 | 用户看到 | 可执行操作 |
|---|---|---|
| `waiting` | 等待上传 | 移除 |
| `validating` | 正在校验 | 等待 |
| `uploading` | 上传中和进度/旋转状态 | 取消 |
| `succeeded` | 上传成功 | 无；成功项不回滚 |
| `failed` | 失败原因 | 单独重试、移除 |
| `canceled` | 已取消 | 重试、移除 |

- 用户关闭仍有 `waiting`、`validating` 或 `uploading` 项的弹窗时，必须二次确认。
- 关闭弹窗不会删除已经成功创建的资产。
- 客户端取消只保证停止等待或中断当前请求；若服务端已完成落库，响应回收时应按成功资产处理，避免重复重试。
- 网络断开、登录失效、服务端校验失败和存储失败均按文件显示，不用一个通用错误覆盖全部队列。

## 7. 展示名称编辑

### 7.1 入口

- 资产卡片名称区域提供改名入口。
- 资产详情页标题区域提供改名入口。
- 非所有者且非管理员不显示编辑入口。

### 7.2 交互

- 点击后原位编辑，默认全选当前展示名称。
- `Enter` 保存，`Esc` 取消，失焦不自动保存以避免误操作。
- 保存前去除首尾空格；结果必须为 1 至 100 个字符。
- 空值或超长时原位显示校验错误，不发送请求。
- 允许与任意资产重名；若同屏存在同名资产可提示但不阻断。
- 请求失败时保留用户输入和编辑状态，显示服务端错误，并允许再次保存。
- 保存成功后同步更新卡片、详情、选择器和当前搜索结果中的名称。

改名不得修改 `filename`、`tos_key`、checksum、所有者、资产类型或引用该资产的业务记录。

## 8. 页面状态

- 加载：素材骨架或加载状态，工具栏保持稳定尺寸。
- 空图库：说明当前筛选下无资产，并提供上传入口。
- 无搜索结果：保留筛选条件，提供清空搜索/筛选操作。
- 无权限：公开资产仍可浏览和选用，但修改操作不展示；直接调用接口返回 403。
- 列表刷新失败：保留已有列表并提示刷新失败，不清空用户已选项。
- 上传部分成功：明确显示成功数、失败数；允许完成后仅选中成功项。

## 9. 兼容与迁移

- 旧资产新增 `display_name` 后，由 `filename` 去掉最后一个扩展名回填。
- 迁移期 API 同时返回 `display_name` 和 `filename`；界面展示优先使用 `display_name`，原始文件名只用于追溯。
- 现有只读取 `filename` 的调用方继续可用，分阶段切换，不能把 `filename` 改成展示名称语义。
- 素材管理组件完成共享化前，不删除现有入口；切换完成并通过页面矩阵验收后再收口导航。

## 10. 验收标准

- 运营、设计师使用同一素材管理页面和相同上传、搜索、筛选、改名、标签、可见性规则。
- 可一次选择 50 张合法图片，实际上传并发不超过 3。
- 单个文件失败不影响其他文件，成功资产不回滚，失败项能独立重试。
- 等待项可移除，上传中可取消，关闭未完成队列有二次确认。
- 完成后自动选中本批成功资产，可继续批量设置可见性和标签。
- 默认展示名称正确去除最后一个扩展名；原始文件名完整保留。
- 所有者和管理员能改名；其他用户不能改名，即使资产公开。
- 展示名称校验、重名、失败保留输入和审计记录均符合本文规则。
- 改名后 TOS key、checksum 和历史资产引用均不变化。
- 产品图和电商模板图可正确筛选，且电商模板图不会进入 `LayerTemplate` 流程。

## 11. 范围外

- 服务端多文件聚合上传接口。
- 批量自动命名、编号模板和批量重命名。
- 基于 checksum、文件名或图片内容的去重。
- 上传成功项回滚或 TOS 对象重命名。
- 运营与设计师在素材管理模块内的差异化权限。
